# 2. Покупка VPS и подготовка доступа

## Перед покупкой проверь

| Проверка | Требование | Статус |
|---|---|---|
| Страна и город сервера | Совпадают с задачей | [ ] |
| Публичный IPv4 | Без CGNAT, отдельный адрес | [ ] |
| Входящий TCP/443 | Разрешён | [ ] |
| Правила провайдера | Tunneling/sing-box разрешён | [ ] |
| Root-доступ и Ubuntu 24.04 | Есть | [ ] |
| Web-console или rescue mode | Есть | [ ] |
| Замена IP / переустановка | Возможна | [ ] |
| Способ оплаты | Подходит | [ ] |
| Тариф | Хватает скорости и трафика | [ ] |
| Status page / SLA / отзывы | Есть | [ ] |

Для одного персонального endpoint ищи минимальный разумный тариф. 10–20 Мбит/с обычно достаточно для Claude, Codex, браузера и обычной работы.

## Минимальная конфигурация сервера

- **OS:** Ubuntu 24.04 LTS
- **Публичный IPv4:** да
- **SSH-доступ:** SSH-ключ вместо пароля
- **Порт SSH:** 22 (если нет причины менять)
- **Firewall провайдера:** понятен (включён/выключен/настраивается вручную)

## Шаг 1. Сгенерируй SSH-ключ

На своём компьютере (терминал macOS/Linux или PowerShell Windows):

```bash
ssh-keygen -t ed25519 -C "vps-reality-key"
```

Нажимай Enter на все запросы пути и пароля, если не хочешь задавать passphrase.

Покажи публичный ключ:

```bash
cat ~/.ssh/id_ed25519.pub
```

Скопируй строку, начинающуюся с `ssh-ed25519 AAAA...`, и вставь в поле «SSH-ключ» при покупке сервера.

Приватный ключ без `.pub` никуда не отправляй:

```text
~/.ssh/id_ed25519
```

## Шаг 2. Создай сервер в панели хостинга

1. Выбери Ubuntu 24.04 LTS.
2. Добавь свой публичный SSH-ключ.
3. Убедись, что сервер получает публичный IPv4.
4. Запиши:

```text
VPS_HOSTING_NAME=PQ.Hosting
VPS_PANEL_URL=https://billmgr.pq.hosting/
VPS_PLAN_NAME=Aluminium
VPS_COUNTRY=Польша
VPS_CITY=Варшава
VPS_PUBLIC_IPV4=[ВСТАВИТЬ_IP_ПОСЛЕ_ПОКУПКИ]
VPS_OS=Ubuntu 24.04 LTS
VPS_INITIAL_SSH_USER=root
VPS_ADMIN_USER=adminproxy
VPS_SSH_PORT=22
LOCAL_SSH_PRIVATE_KEY_PATH=~/.ssh/id_ed25519
VPS_PROVIDER_FIREWALL=выключен
REALITY_HANDSHAKE_HOST=www.microsoft.com
```

## Шаг 3. Первый вход по SSH

После получения IP выполни:

```bash
ssh root@[IP_ВАШЕГО_СЕРВЕРА]
```

Если используешь нестандартный ключ:

```bash
ssh -i ~/.ssh/id_ed25519 root@[IP_ВАШЕГО_СЕРВЕРА]
```

При успешном входе появится приветствие `Welcome to Ubuntu 24.04 LTS` и командная строка `root@...:#`.

Проверь на сервере:

```bash
uname -a
lsb_release -a
sudo ss -ltnp
sudo ufw status verbose
```

Ожидаемый результат:

- Ubuntu 24.04 LTS;
- TCP/443 свободен;
- текущие правила firewall понятны;
- нет чужой действующей конфигурации sing-box.

## Шаг 4. Зафиксируй всё в одном месте

Скопируй заполненный блок выше в безопасное локальное хранилище (менеджер паролей, зашифрованная заметка). Не храни эти данные в публичном репозитории.

## Готовность к следующему этапу

Перед переходом к [`03-server-setup.md`](./03-server-setup.md) у тебя должно быть:

- [ ] Куплен VPS с Ubuntu 24.04 и публичным IPv4.
- [ ] Работает SSH-вход по ключу.
- [ ] Заполнены все поля блока выше.
- [ ] Известен статус firewall провайдера.
- [ ] Выбран `REALITY_HANDSHAKE_HOST` — `www.microsoft.com`.

После покупки замени `[ВСТАВИТЬ_IP_ПОСЛЕ_ПОКУПКИ]` на реальный `VPS_PUBLIC_IPV4` и возвращайся.
